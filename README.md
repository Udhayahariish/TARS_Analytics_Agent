# 🤖 TARS – Universal AI Data Analyst

> **Transform any CSV dataset into actionable insights using AI-powered natural language analytics.**

TARS is an intelligent AI Data Analyst that allows users to upload CSV datasets and interact with them using plain English. Instead of writing SQL queries, Python code, or complex formulas, users can simply ask questions and receive instant insights, statistics, visualizations, and business recommendations.

Whether you're analyzing sales, finance, healthcare, HR, inventory, education, or customer data, TARS acts as your personal AI analyst.

## 🚀 How It Works

### Step 1

Upload any CSV dataset.

### Step 2

TARS automatically analyzes the dataset structure.

### Step 3

Ask questions in natural language.

Examples:

```text
What are the top-selling products?

Show monthly revenue trends.

Which region generated the highest profit?

Find correlations between sales and discounts.

Create a visualization of customer growth.
```

### Step 4

TARS generates:

* Insights
* Statistics
* Visualizations
* Business Recommendations
